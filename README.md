# 📈 IntelliFin
**IntelliFin- Intelligent Multi-Asset Analytics Hub** is a financial monitoring and advisory application that bridges daily cash flow with high level asset portfolio tracking. By unifying historical transaction logs and asset metrics inside a single conversational context window, the platform enables an AI Copilot to deliver comprehensive, cross-domain financial insights.

## 🔗 Live Deployment
You can access the live version here:
https://intellifin.netlify.app/

## ✨ Features
- AI Conversational Copilot: An intelligent advisory assistant driven by Large Language Model (LLM) intent parsing. Built using LangGraph to route user queries dynamically. The chat engine reasons through user prompts and dynamically executes system tools to extract financial metrics across data domains.
- Multi-Asset Schema Integration: Unifies transactional cash flow data and investment asset distributions into a standardized backend data layer, enabling seamless cross-domain analysis.
- Performance-Optmized Ledger: Protects browser memory and client-side performance by utilizing cursor-based pagination on the backend to fetch chronological transaction logs on demand.

## 🛠️ Tech Stack
- Frontend: React (TypeScript), Recharts
- Backend: Python, Flask, LangGraph
- Database: MongoDB (Users, Transactions, Subscriptions), Qdrant (Vector Store for RAG)
- Styling: Tailwind CSS, Lucide Icons
